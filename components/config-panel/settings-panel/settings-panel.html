Shortcuts
Ctrl + Arrow Left
Move text cursor to previous word.
Ctrl + Arrow Right
Move text cursor to next word.
Ctrl + Arrow Up
Move text cursor to closest word in previous line.
Ctrl + Arrow Down
Move text cursor to closest word in next line.
Ctrl + Shift + Arrow Left
Highlight from the current cursor position to the start of the previous word.
Ctrl + Shift + Arrow Right
Highlight from the current cursor position to the end of the next word.
Ctrl + Shift + Arrow Up
Highlight from the current cursor position to the closest position in the previous line.
Ctrl + Shift + Arrow Down
Highlight from the current cursor position to the closest position in the next line.
Ctrl + Alt + Arrow Left
Move to the task in the previous list
Ctrl + Alt + Arrow Right
Move to the task in the next list.
Ctrl + Alt + Arrow Up
Move to the task in the previous list.
Ctrl + Alt + Arrow Down
Move to the task in the previous list.
