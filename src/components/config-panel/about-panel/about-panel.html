App

This custom element is a full implementation of a taskboard manager app using the example name MyBoards.

The element, itself, is a full application that can be hosted in any html page in an environment that supports javascript (like your browser!).

If you would like to see an example of this element used as a Single Page App (SPA) using url query routing, see the DemBoards example. This implementation updates the browser's url, but does not update the path; only the query string (everything after a question mark).

If you would like to see an example of this element used as a Progressive Web App (PWA), see the DozeBoards example. This implementation updates the browser's url and uses the current path for routing.

To find out more about the application, and the project that created it, visit taskboard-manager.com
